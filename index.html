Kid Adventure

Carry one item at a time. Grab the sword to fight dragons, use the bridge to pass through walls, and match colored keys to their gates. The white key opens any gate. Return the trophy to the start pedestal to win.

How to Play

1. Find the sword and bridge near the start routes.
2. Match yellow, black, and green keys to their gates (white key opens any gate).
3. The bat steals items and drops them in other rooms.
4. Defeat dragons with the sword, then bring the trophy home.
Adventure Mode keeps one dependable world. Remix Mode keeps the same rules but rotates the map.
Switching heroes reloads their art instantly and respawns you near the start.
Adventure Mode is the steady castle quest. Remix Mode rotates through larger family remix maps.

Game

Touch Controls

Controls

Move: WASD / Arrows
Pick up / Use: E  ·  Drop: Q

Key Bindings

Click a binding button, then press a key. Press Esc to cancel remapping.

Notes

Images are scaled to the entity size after loading from disk. Update the PNGs in each kid folder and refresh to see them in game. Transparent backgrounds look best. Adventure Mode keeps one teachable world so the quest feels consistent. Remix Mode trades that stability for surprise routes and bigger detours.
